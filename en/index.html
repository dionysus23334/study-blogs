04 / About

I'm Yuxi Guo, studying at HKUST.

This site is the front door to my study archive. The two course sites and the mathematics note are built with MkDocs; the palette, type, and the CSS on this page are hand-written. Everything here comes from slides, lectures, and my own notes.

I keep notes for a simple reason: if I don't write it down, I assume I know it. The glossaries exist so the first time I meet an abbreviation I don't have to guess; the homework retrospectives exist so I remember the mistakes, not just the answers. Every so often I also build a small project — learning is not only taking knowledge in, but also taking it out and using it.
