About this demo

This is a study concept demo for a personal learning archive, not an official Cloudflare or 1.1.1.1 product. It does not install a VPN, change DNS, or contact any network. The interface and the copy are original, with no official logo, cloud mascot, screenshots, or slogans. The picture is a vertical rule and a mark that slides on a line. Practice Station is an invented site. The two bars are marked as an illustration, not a measurement of speed. The switch only redraws the diagram on this page. A refresh turns it off again.
